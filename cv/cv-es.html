Proyectos

Sistema Jurídico proyectosena.online/sistema-juridico
Plataforma web para administrar casos legales, expedientes y actuaciones. Es el proyecto más grande que he hecho, y está desplegado y accesible en línea.
  • Autenticación con JWT y contraseñas cifradas con bcrypt; la API va detrás de Helmet, CORS y limitación de peticiones.
  • Los documentos de cada expediente se guardan en Cloudflare R2, no en el disco del servidor; los PDF se generan con PDFKit.
  • Desplegado con Docker Compose —incluido su propio contenedor de PostgreSQL— y servido por Nginx. Pruebas con Jest, Supertest y Cypress.
Stack: React 19 · Vite · Tailwind · shadcn/ui · Node 22 · Express · PostgreSQL 16 · Prisma · JWT · Cloudflare R2 · Docker · Nginx
Costura App (Atelier Manager) proyectosena.online/costura
Gestión de pedidos y medidas para un taller de costura, en el celular y en la web. Nació de un requisito concreto: que la modista pueda trabajar sin señal.
  • Vue 3 empaquetado a Android con Capacitor 8; los datos viven en SQLite nativo dentro del dispositivo y suben solos al reconectar.
  • Actualizaciones por aire con Capacitor Updater, sin reinstalar la aplicación.
  • Pruebas unitarias con Vitest y de flujo completo con Playwright, ejecutadas en cada push por GitHub Actions.
Stack: Vue 3 · Vite · JavaScript · Capacitor 8 · SQLite · Android · GitHub Actions
Sincronización Web / App nativa github.com/Aryannext
Cómo se ponen de acuerdo una app Android nativa y una plataforma web cuando ninguna de las dos tiene internet garantizado.
  • Cada registro lleva un UUID y un número de versión, para resolver qué pasa cuando los dos lados cambiaron el mismo dato.
  • App Android en Kotlin con Room y WorkManager; centro de mando en React y API en Express 5 sobre PostgreSQL.
Stack: React 19 · Vite · Express 5 · PostgreSQL · Kotlin · Room · WorkManager · SQLite
